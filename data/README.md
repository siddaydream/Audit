# data/ 参考库目录

本仓库已包含以下五份文件和 `manifest.json`。下载解压后无需另行复制或首次登记：

1. 绿色能效数据明细（文件名含"绿色能效"，两份，保留 -1 / -2 后缀）
2. 环保关键名单（文件名含"环保关键名单"，使用其中"总名单1017"工作表）
3. 政策审核要求（文件名含"政策审核要求"）
4. 《2017国民经济行业分类注释》（文件名含"国民经济行业分类"）

登记后生成 `manifest.json`（记录文件名与 SHA256）。五份参考文件经用户授权随本仓库分发，每期业务表格不上传。

收到新快照时：替换对应文件 → 重跑 `python run.py init-data`。

两份绿色明细以 `bundled/` 分块分发，首次审核或登记时自动还原并校验；请勿删除分块。
